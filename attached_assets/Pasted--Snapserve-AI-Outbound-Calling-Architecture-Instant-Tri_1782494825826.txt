# Overall Platform Architecture

```text
                                   SNAPSERVE AI

                        ┌───────────────────────────────┐
                        │   OUTBOUND CALLING PLATFORM   │
                        └───────────────────────────────┘


                    ┌─────────────────┐      ┌─────────────────┐
                    │ Instant Trigger │      │ Campaign Engine │
                    └────────┬────────┘      └────────┬────────┘
                             │                        │
                             ▼                        ▼
                   Event Driven Calls          Bulk Outbound Calls
                             │                        │
                             └──────────┬─────────────┘
                                        ▼
                              Automation Engine
                                        │
                                        ▼
                              Compliance Engine
                                        │
                  ┌──────────────────────────────────────┐
                  │ Business Hours                       │
                  │ TRAI Calling Window                  │
                  │ Timezone (Optional)                            │
                  │ Working Days (Optional)              │
                  └──────────────────────────────────────┘
                                        │
                           ┌────────────┴─────────────┐
                           │                          │
                     Allowed                     Not Allowed ( lead came outside the calling window) 
                           │                          │
                           ▼                          ▼
                    Create Call Job           Pending Queue
                           │                          │
                           ▼                          ▼
                     AI Voice Agent          Scheduler Service
                           │                          │
                           └──────────────┬───────────┘
                                          ▼
                                 Call Execution Engine
                                          │
                                          ▼
                      Recording • Transcript • CRM • Analytics
```

# Flow 1 - Instant Trigger Engine

## Supported Trigger Sources

```text
Meta Ads
Website Forms
CRM
API Trigger
Google Sheets
Webhooks
Manual Trigger
```

```text
Trigger Event
      │
      ▼
Receive Lead
      │
      ▼
Lead Validation
      │
      ▼
Automation Workflow
      │
      ▼
Compliance Engine
      │
      ├── Business Hours
      ├── TRAI Calling Window
      ├── Timezone
      └── Working Days
      │
      ├── Allowed
      │      │
      │      ▼
      │ Create Call Job
      │
      └── Not Allowed (Out side the calling window)
             │
             ▼
      Pending Queue
             │
             ▼
 Scheduler Executes Later (In the next working or calling hours)
```

# Flow 2 - Campaign Engine (Bulk Calling)

Campaigns are initiated manually by users and execute outbound calls in bulk.

## Campaign Data Sources

```text
CSV Upload
Excel Upload
CRM Import
Google Sheets Import
API Import
```

---

# Campaign Execution Flow

```text
Campaign Started
        │
        ▼
Load Contacts
        │
        ▼
Maintain Configured Concurrency
        │
        ▼
500 Active Calls Running
        │
        ▼
Call Ends
        │
        ▼
Pick Next Contact
        │
        ▼
Start New Call
        │
        ▼
Maintain 500 Active Calls Until Campaign Completes
```

```text
        │
        ▼

        │
        ▼

        │
        ▼

        │
        ▼

        │
        ▼
```

```text
Transcript

```
