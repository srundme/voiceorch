I want to simplify the entire AI Knowledge system and remove the dependency on embeddings, vector databases, and semantic search for now.

Our goal is to launch a reliable MVP quickly.

## New AI Knowledge Architecture

Remove:

* Embeddings generation
* Vector storage
* pgvector dependency
* Similarity search
* Embedding models
* Chunk overlap settings
* Embedding API calls

We no longer want Retrieval-Augmented Generation based on vector embeddings.

---

## New Knowledge Storage Design

Create a simple PostgreSQL-based knowledge system.

### knowledge_sources

Store:

* id
* user_id
* name
* type (faq, document, website, text)
* status
* created_at
* updated_at

### knowledge_entries

Store:

* id
* source_id
* title
* content
* keywords
* created_at

All uploaded information should be converted into readable text entries and stored in this table.

## Knowledge Search System

Replace vector search with PostgreSQL Full Text Search.

Use:

tsvector

tsquery

GIN indexes

Search process:

1. User asks a question.
2. Search knowledge_entries using PostgreSQL Full Text Search.
3. Return the top 3–5 matching entries.
4. Pass those entries to the LLM.
5. Generate the final answer.

---
