2. Real-Time Streaming Pipeline

This is the hardest technical problem.

A normal chatbot works:
INPUT → THINK → OUTPUT

Voice AI cannot work like that.

Bolna streams everything simultaneously:

User speaks →
STT streams partial text →
LLM starts thinking before sentence ends →
TTS starts generating before full response →
audio streams back instantly

This reduces latency massively.

Without orchestration:

calls feel robotic
long pauses happen
interruptions break flow

Bolna’s orchestration pipeline handles:

chunk streaming
token streaming
partial transcripts
audio buffering
turn-taking

This is elite infra work.

3. Interruption Handling (Barge-In)

Humans interrupt constantly.

Example:
AI: “Can you please confirm your—”
User: “Yeah yeah it’s Ravi!”

The system must:

stop TTS immediately
cancel pending tokens
restart context
avoid overlap

This requires:

websocket event handling
audio stream cancellation
realtime speech detection
conversational state management

This is a BIG engineering challenge.
