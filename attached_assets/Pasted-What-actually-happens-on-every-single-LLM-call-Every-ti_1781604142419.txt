What actually happens on every single LLM call:
Every time the user finishes speaking, the agent does this exact sequence — STT converts speech to text → agent packages the full system prompt + entire conversation history so far → sends it all to the LLM → LLM responds → TTS converts the response to audio → user hears it.
The problem is that "full system prompt" part. Your OPTM system prompt is roughly 2000 tokens. By turn 20 of a call, the agent is sending 2000 tokens of system prompt that hasn't changed at all, plus 2500 tokens of conversation history from previous turns, plus the new user message. That's 4500+ tokens, and the LLM bills you for all of it — even though 2000 tokens of it is identical to what you sent on turn 1.
The four fixes, in order of how easy they are to implement:
KV Cache is the easiest — Anthropic, OpenAI and Gemini all support this. The system prompt gets cached on their server after the first call. Every call after that, the system prompt is served from cache and you pay maybe 10% of the normal cost for it. Zero code change on your side, just enable it in your API settings.
Sliding window is the next easiest — instead of sending all 19 previous turns to the LLM on turn 20, you only send the last 8 turns. The risk is the agent might forget the patient's name from turn 1, so you have to keep key facts pinned.
Stage trimming is the most impactful for Bolna agents specifically — your OPTM prompt has sections for opening, empathy, X-ray check, treatment explanation, booking, closure, objection handling, and pricing. At turn 20 you're at the booking stage. Why send the treatment explanation and X-ray sections? You only send the active stage section + the core identity block. This can cut your system prompt from 2000 tokens to 400 tokens.
Summarization compresses old turns — instead of sending turn 1 through 15 raw, you summarize them into 100 tokens ("Patient confirmed knee pain for 2 years, no X-ray done, interested in treatment, agreed to book appointment") and only send that summary plus the last 5 turns raw.
