# SnapServe — Sidebar & Navigation Restructure Spec

Goal: reduce navigation from 26 destinations (17 primary + 9 settings) to 14 (10 primary + 4 settings) with ZERO features removed. Everything merged survives as a tab inside a parent page. All old routes must redirect. Target audience is non-technical business users, so all renames below are intentional — do not keep old labels.

---

## 1. Sidebar layout (top to bottom)

1. **Header**: SnapServe logo + collapse chevron (unchanged). Global Search input with ⌘K shortcut (unchanged — searches agents, calls, contacts, KBs).
2. **Primary CTA button**: `+ New agent` — full-width, accent-colored, sits directly below search. On click → opens the Vibe Build wizard (`/app/vibe`). Inside the wizard, add a small secondary link "Start from scratch instead" that creates a blank agent (the current New Agent behavior). Vibe Build is REMOVED as a nav item — this button is its only entry point.
3. **Primary navigation** (Zone 1): grouped items, see Section 2. Group labels are small uppercase muted text. Groups are NOT collapsible.
4. **Settings** (Zone 2): a single "Settings" row with a chevron. Clicking expands the settings sub-items in place (no page navigation). Auto-expand when the current route is any settings route. See Section 3.
5. **Footer** (Zone 3, pinned to bottom): see Section 4.

## 4. Zone 3 — Footer (pinned bottom)

Keep the existing footer exactly, in this order:
1. Documentation link (BookOpen → /docs)
2. Wallet chip — live balance. Colors: green ≥ ₹500, amber ≥ ₹100, red < ₹100. Clicking it → /app/wallet.
3. Status badge — "All systems operational"
4. Privacy / Terms links
5. User profile row (name + initials) → popover with Settings shortcut, theme toggle, Sign out

**Header change (top bar, not sidebar):** REMOVE the red balance pill from the top-right header. The footer wallet chip is now the single balance indicator. If keeping a header indicator is required, it must follow the same green/amber/red thresholds — never red by default.

## 6. Badge rules

- ONE badge in the whole sidebar: pending callbacks count on the **Call Logs** item (amber pill, e.g. "3"). Show only when count > 0.
- No other sidebar item gets a badge or count. Do not add badges to Campaigns, WhatsApp, etc.

## 8. Mobile behaviour

- Bottom tab bar (5): **Home, Create** (was "Vibe" — opens Vibe Build wizard), **Agents, Calls, Wallet**.
- Hamburger opens a drawer with the full Zone 1 + 2 + 3 structure above.
- Desktop collapsed mode: icon-only, group labels hidden, group separators (thin dividers) retained.

---

## 9. Tab component behaviour (all merged pages)

- Tabs render below the page title, horizontal, underline style consistent with the existing agent-detail tabs.
- Active tab syncs to `?tab=` in the URL (shareable links).
- Each tab lazy-loads its content — the merged pages must not fetch data for hidden tabs.
- Existing page components are reused as-is inside tabs (no rewrite of Callbacks/Transfers/Meta Leads/etc. logic — this is a navigation refactor, not a feature refactor).
