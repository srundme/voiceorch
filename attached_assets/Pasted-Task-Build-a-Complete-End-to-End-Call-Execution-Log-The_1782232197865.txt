Task: Build a Complete End-to-End Call Execution Log

The current Logs tab only shows a few high-level events (Memory, STT, LLM, TTS, Tool calls). It is not sufficient for debugging production AI voice calls.

I want the Logs tab to become a complete execution trace of the entire call.

The goal is that a developer should be able to understand everything that happened during a call without opening server logs or inspecting raw JSON.

The log should capture every stage of the pipeline from the moment the call starts until it ends.

Goal

The Logs tab should act as a complete execution timeline for the call. Every important action, transition, retry, fallback, warning, interruption, provider event, and error should be recorded in chronological order so that developers can identify the exact root cause of any issue without needing backend logs or raw JSON.
