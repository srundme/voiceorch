# Fix Calendar Booking Tools Architecture

## Current Situation

The booking tools UI is incomplete and currently unusable.

The platform already supports:

✓ Agent Calendars
✓ Google Calendar Connection
✓ Event Creation
✓ Event Types
✓ Booking Infrastructure

However the booking tools are not properly wired together.

This is blocking appointment booking functionality.

---

# Problem 1

Book Appointment

The Event Type dropdown is not loading the event types that already exist for the assigned calendar.

Current:

Book Appointment

Assigned Calendar:
Sarii test cal

Event Type:

Any Event Type

Only one option appears.

Expected:

Any Event Type

Discovery Call

Consultation

Demo

Test 1 to 1

etc.

The tool must automatically load all event types belonging to the assigned calendar.

---

# Problem 2

Check Availability

Same issue.

The Event Type dropdown is empty.

This tool cannot properly check availability without knowing which event type availability should be checked.

Expected:

Load all event types from the assigned calendar.

---

Assigned Calendar

Selected Event Type
