## Task: Replace Custom Backchannel Phrases with Default Language-Based Fillers

Currently, the **Backchanneling** section contains a **Custom Phrases** input field where users can enter their own filler phrases.

We want to simplify the experience and provide a consistent, high-quality voice experience across all supported languages.

### UI Changes

* Remove the **Custom Phrases** text field completely.
* Users should no longer be able to add or edit filler phrases.
* Keep only:

  * **Backchanneling** toggle
  * **Frequency** slider

### Backend Behavior

When **Backchanneling** is enabled:

* Automatically use predefined filler phrases based on the agent's selected language.
* Users should not have to configure anything.
* The backend should randomly choose from the predefined fillers for that language so conversations sound natural and less repetitive.
* Whenever the agent language changes, the filler phrases should automatically switch to the corresponding language.

### Requirements

* These default filler phrases should be maintained internally in the backend.
* Users must not be able to edit or override the filler phrases.
* The backend should automatically select filler phrases based on the agent's selected language.
* **Strictly use filler phrases only from the selected language.**
* **Never use, mix, or fall back to filler phrases from any other language.**
* For example, if the agent language is **Tamil**, it must use **only Tamil** filler phrases. If the agent language is **English**, it must use **only English** filler phrases. The same rule applies to every supported language.
* If a language does not have predefined filler phrases, do not fall back to another language.
* Randomly vary the filler phrases during conversations to avoid repetition.
* Fillers should be spoken naturally and contextually while the agent is processing the user's request.
* Preserve the existing Backchanneling functionality. Only replace the custom phrase configuration with predefined, language-specific fillers.

### Important

Do not change any existing backend logic for Backchanneling other than replacing user-defined filler phrases with the predefined language-specific defaults. The goal is to make Backchanneling work automatically and consistently across all supported languages while providing a simpler user experience.
