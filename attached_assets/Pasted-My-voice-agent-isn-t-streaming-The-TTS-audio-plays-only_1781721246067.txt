answer is ready, and the transcript text appears all at once afterward. I want

SnapServe is an OpenAI-compatible LLM proxy. Voice platforms point their api_base
at it; it injects caller memory into the request and must stream the completion
back as SSE. Latency-sensitive (deployed on Railway).

PRIMARY HYPOTHESIS
The proxy is breaking the stream. Either it calls the upstream LLM with
stream=False and returns one string, OR it sets stream=True but buffers all
chunks and yields them at the end, OR the web framework/response isn't a true
streaming response so it gets buffered before the client.
