# Feature Request: Agent Simulation Testing (Chat + Persona-Based Testing)

IMPORTANT:

Before making any changes:

1. Create a separate feature branch.
2. Do NOT modify existing call flows.
3. Do NOT modify voice calling.
4. Do NOT modify agent execution.
5. Do NOT modify tools.
6. Do NOT modify memory.
7. Do NOT modify appointment booking.
8. Do NOT modify CRM.
9. Do NOT modify analytics.
10. Do NOT modify production agent behavior.

This must be implemented as a completely isolated feature.

--------------------------------------------------

# Objective

Build a Simulation Testing module similar to Retell AI.

The purpose is to allow users to test an AI Agent before deployment.

Users should be able to:

1. Manually chat with the agent.
2. Run simulated conversations.
3. Test different customer personas.
4. Validate prompts.
5. Validate tool calling.
6. Validate variable injection.
7. Validate memory behavior.
8. Validate appointment booking flows.
9. Validate lead qualification flows.

This feature should work WITHOUT making actual phone calls.
