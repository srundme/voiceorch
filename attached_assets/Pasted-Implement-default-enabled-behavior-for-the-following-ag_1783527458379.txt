- Do not only display them as ON in the UI; verify that the actual saved backend configuration is ON.

- If the architecture allows it, use a shared default configuration so both manual creation and Vibe Builder creation stay consistent.
- Ensure API serialization, database persistence, and agent-fetch responses preserve these values correctly.

- Do not affect any unrelated configuration, prompt generation, Refine with AI behavior, LLM selection, STT, TTS, voice configuration, call flow, knowledge base, or other agent features.

Every newly created agent, regardless of whether it is created manually or through Vibe Builder, must have Noise Cancellation, End Call Tool, Backchanneling, and Call Recording enabled by default in both the backend configuration and the agent configuration UI.
