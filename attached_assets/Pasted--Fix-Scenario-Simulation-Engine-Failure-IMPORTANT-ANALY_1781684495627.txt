# Expected Behavior

The Scenario Simulation should create a virtual customer persona.

Example:

Priya

27 years old

First-time health insurance buyer

Budget conscious

No pre-existing diseases

Confused about insurance terminology

Looking for a plan under ₹8,000

The Persona AI should then interact with the Agent.

Agent:

Health Insurance Advisor

Persona:

Potential Customer

The conversation should continue naturally until:

- Goal completed
- Success criteria evaluated
- Max turns reached

---

# Suspected Root Cause

Based on the failure logs, it appears the Persona Generator is producing chain-of-thought style output.

Example:

<think>
I need to act like Priya...
I should ask about deductibles...
I should continue the conversation...
</think>

Instead of generating an actual customer message.

This suggests the simulation engine is passing reasoning text into a tool/function schema that expects a customer response.

---

# Required Behavior

The Persona Engine should ONLY generate the next customer message.

Example:

Correct:

"What exactly is a deductible?"

OR

"Do you have any plans under ₹8,000 per year?"

OR

"I already have insurance. Can I port it?"

---

Never:

<think>
I need to ask about deductibles...
</think>

Never expose reasoning.

Never expose chain-of-thought.

Never expose planning text.

Only generate customer-facing messages.

---

Expected Flow:

The Persona should behave like a customer.

The Persona should NOT behave like an LLM agent.

The Persona should NOT call tools.

The Persona should NOT execute functions.

The Persona should NOT generate system instructions.

The Persona should NOT generate reasoning.

# Tool Calling Rules

Critical Requirement

Only the Agent may call tools.

Examples:

check_availability()

cancel_booking()

CRM functions

Webhook functions

Knowledge functions

Memory functions

---

The Persona must NEVER attempt tool execution.

If the Persona can call tools, disable it.

The Persona only generates user messages.

# Prompt Engineering Fix

The Persona Prompt should enforce:

"You are a customer in a conversation.

Your task is ONLY to generate the next message the customer would say.

Do not explain your reasoning.

Do not generate chain-of-thought.

Do not generate analysis.

Do not generate system instructions.

Do not generate XML tags.

Do not generate JSON.

Do not generate tool calls.

Output only the customer's next spoken message."
