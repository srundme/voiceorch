1. **User ID** — the actual logged-in user, from auth/session/request headers
2. **Session ID / Conversation ID** — the thread or session identifier that groups multiple turns together

5. **Success** — whether the call succeeded (set to `false` on exceptions)
6. **Agent name / Tool name** — the logical name of the agent or tool being invoked (MCP tool name, chat agent name, etc.)

## SDK TypeScript

Install: `npm install agnostai`

```typescript
import * as agnost from 'agnostai';
agnost.init('aaba3367-0081-4ee1-9319-c1b604fff441');

// At login / session start — pass any arbitrary key: value pairs for this user.
agnost.identify(<actualUserId>, {
  <userKey1>: <userValue1>,
  <userKey2>: <userValue2>,
  // ... add whatever keys are meaningful for this project
});

// Wrap every turn. Same conversationId across turns in one thread.
const interaction = agnost.begin({
  userId:         <actualUserId>,
  agentName:      <agentOrToolName>,
  input:          <userMessageOrToolArgs>,
  conversationId: <threadOrSessionId>,
  properties:     { <key1>: <value1>, <key2>: <value2> }, // arbitrary metadata relevant to this codebase
});

try {
  const output = await <call your LLM / tool>;
  interaction.setProperties({ <key>: <value> }); // add more arbitrary metadata as you discover it
  interaction.end(output);                       // success defaults to true
} catch (err) {
  interaction.end(String(err), false);           // mark this turn as failed
}

// On process shutdown
await agnost.shutdown();
```
