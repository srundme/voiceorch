Call problems I'm seeing (Agent 59, VoBiz inbound, Tamil)
On every inbound call:

~6 seconds of dead air at the start — no greeting, no ambient
Barge-in / interruption does not work — I can't talk over the agent
Heavy latency on every turn
Sarvam STT is inaccurate; when I ask for English the agent stays in Tamil
Root causes in code:

Returning callers trigger an LLM greeting with the full 31k system prompt instead of a short one
A self-echo gate blocks caller audio from reaching Sarvam STT unless energy > 1200, so barge-in never fires
greetingEchoHoldUntil blocks barge-in for the full greeting (~7s)
autoSwitchToEnglish is not wired into pipeline AgentConfig, so English requests are ignored in strict Tamil mode

const GREETING_ECHO_HOLD_CAP_MS = 3000;
function buildCompactGreetingPrompt(fullSystemPrompt: string, language: string): string {
  const memoryMatch = fullSystemPrompt.match(
    /=== CALLER MEMORY[\s\S]*?=====================================/,
  );
  const memoryBlock = memoryMatch?.[0] ?? "";
  const langName = LANG_DISPLAY_NAMES[language] ?? language;
  const parts = [
    memoryBlock,
    `[LANGUAGE] Respond ONLY in ${langName}.`,
    "[OPENING LENGTH] Your opening line must be ONE short, natural sentence — a brief greeting only. Do not list services, ask multiple questions, or explain anything yet; wait for the caller to respond.",
  ].filter(Boolean);
  return parts.join("\n\n");
}
