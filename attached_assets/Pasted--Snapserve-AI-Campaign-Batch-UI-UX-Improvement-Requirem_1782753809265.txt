# Snapserve AI – Campaign & Batch UI/UX Improvement Requirements

## Objective

The current Campaign and Batch modules are functionally working well. I do **not** want to introduce any new backend logic, APIs, database changes, or business logic.

This task is **purely a UI/UX refinement** to improve usability, readability, consistency, and reduce user effort while keeping all existing functionality intact.

The goal is to make the interface feel more polished and enterprise-grade without changing how the system works.

---

# General Design Principles

Throughout the Campaign and Batch modules:

- Improve visual hierarchy.
- Increase whitespace between sections.
- Improve typography hierarchy.
- Keep spacing consistent.
- Use consistent status colors across every page.
- Make important metrics visually prominent.
- Reduce visual clutter.
- Improve scanability.
- Do NOT modify backend logic or workflows.

---

# 1. Campaign Overview

## Current Issues

- KPI cards are too small.
- Funnel feels disconnected from KPIs.
- Batch cards don't immediately communicate their status.
- Everything has similar visual weight.

## Improvements

### KPI Cards

Increase the size of the KPI cards.

Current KPIs:

- Leads
- Called
- Connected
- Booked
- Callbacks
- Transfers

Make the values larger and easier to scan.

Example hierarchy:

- Label (small)
- Metric (large)
- Optional percentage (small)

No backend changes required.

---

### Funnel

Example flow:

↓

Called
↓

Connected
↓

Interested
↓

Booked
↓

Transferred

This should naturally guide the user's eyes from left to right.

# Important Constraints

This task is strictly a UI/UX refinement.

Do NOT:

- Change backend logic.
- Change API contracts.
- Change routing.
- Change database schema.
- Introduce new business logic.
- Modify campaign execution.
- Modify batch execution.
- Add new workflows.
- Change calculations.

Only improve:

- Layout
- Typography
- Alignment
- Visual hierarchy
- Grouping
- Spacing
- Colors
- Scanability
- Readability
- Overall user experience

The objective is to make the existing product feel cleaner, more intuitive, and enterprise-ready while preserving 100% of the current functionality.
