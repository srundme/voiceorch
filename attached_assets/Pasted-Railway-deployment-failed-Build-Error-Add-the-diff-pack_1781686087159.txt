## Problem
The @workspace/api-server service fails at the BUILD_IMAGE stage. The Dockerfile builds the dashboard first via `pnpm --filter @workspace/dashboard run build`, which runs `vite build`. Vite/Rollup fails with:
```
Rollup failed to resolve import "diff" from "/workspace/artifacts/dashboard/src/pages/agents/builder.tsx"
```
The build uses `pnpm install --frozen-lockfile`, so only packages declared in package.json and present in pnpm-lock.yaml are installed.

## Diagnosis
`artifacts/dashboard/src/pages/agents/builder.tsx` line 2 contains:
```ts
import { diffWords, diffWordsWithSpace } from "diff";
```
This import was added in the current commit as part of "push current post-merge state" for builder.tsx. However, the `diff` package was never added to `artifacts/dashboard/package.json`. The package has no entry in either `dependencies` or `devDependencies`, so pnpm does not install it and Rollup cannot resolve it at bundle time.

## Fix
1. **File:** `artifacts/dashboard/package.json`
2. **Current content** (last entry in devDependencies):
```json
    "zod": "catalog:"
  }
}
```
3. **Replace with:**
```json
    "diff": "^7.0.0",
    "zod": "catalog:"
  }
}
```
4. After editing `package.json`, run `pnpm install` from the repo root to regenerate `pnpm-lock.yaml`. Both files must be committed together.
5. **Why:** This adds the `diff` package that `builder.tsx` imports. The `--frozen-lockfile` flag in the Dockerfile requires the lockfile to be in sync with `package.json`, so both must be updated.
