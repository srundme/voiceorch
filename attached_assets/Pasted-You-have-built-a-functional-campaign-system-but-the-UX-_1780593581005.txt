You have built a functional campaign system, but the UX architecture does not match the actual business workflow of an AI voice campaign platform.

The current implementation feels like a developer/admin CRUD tool. It exposes technical concepts too early in the workflow and mixes campaign-level configuration with batch-level execution settings.

We need to restructure the Campaign module around how operations teams actually think.

---

## CURRENT PROBLEMS

1. Campaign Creation is Too Technical

Current Campaign Creation Modal contains:

* Campaign Name
* Description
* Agent
* Field Mappings
* Call Delay
* Max Attempts
* From Number Override

This is incorrect.

At campaign creation time:

* User has not selected a lead source.
* User has not uploaded CSV.
* User has not selected Meta Form.
* User does not know available columns.

Therefore:

Field Mappings do not belong at Campaign level.

CSV concepts do not belong at Campaign level.

Retry settings do not belong at Campaign level.

Call delay does not belong at Campaign level.

These are execution settings and must belong to Batch creation.
