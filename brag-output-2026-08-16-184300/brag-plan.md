# Brag Plan: SnapServe Meeting Agents (live tutorial)

## What is this app?
SnapServe voice agents join Google Meet, Zoom, and Teams, talk on camera, and present slides (`next_slide` / `goto_slide`).

## The angle
**Dashboard tutorial, not a slideshow.** Live HTML UI, a cursor, character-by-character typing, a click, then the same page updates. Meet and the deck are built components — no flattened plates as photos.

## Hook
Logo + **Send an agent into Google Meet or Zoom.**

## Key moments
1. Meeting bots: pick Voiceathon → type a Meet URL → Join meeting → In call
2. Built Meet chrome: agent on camera, speaking
3. Built deck: lines write in; `next_slide`; 3/12 → 4/12

## Outro
Meet · Zoom · Teams. Meeting agents. Live now. app.snapserve.ai

## Tone
- Preset: polished
- Direction: black/grey studio, official three-bar mark + headset agent only
- Music: vol-12 @ 0.18 (VO bed)

## Format: square 1080×1080
## Duration: 25s

## Storyboard
1. 0–2.5 — Claim. Mark + one sentence.
2. 2.5–11.0 — Setup + result on one live Meeting bots page (cursor, type, click, In call).
3. 11.0–16.5 — Talk. Built Meet tiles + caption.
4. 16.5–22.0 — Present. Built deck + next_slide + counter.
5. 22.0–25.0 — Rooms + live now.
