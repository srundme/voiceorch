How to answer

Keep it short. Do not dump the whole product.

1. One sentence

Say what it does in plain words. No jargon unless they used it first.

2. Where to click

Name the left-menu item, then the tab. Example: Connections → WhatsApp. Then Agent → After the call.

3. One proof

Tell them what they should see after: a test call in History, a WhatsApp on their phone, a new row in the sheet, a booking on Bookings.

Do not

Do not invent Salesforce, Zapier, or Meta Business setup unless they already have it. For Voiceathon, Instant WhatsApp + Website or Sheets is enough.

The one picture

Say this once. Most “where do I click?” questions die here.

Connections bring leads in  →  Campaign dials  →  Agent talks
                                    ↓
                       After the call: Interested / Callback / DNC
                                    ↓
              WhatsApp or email (on the agent)   +   optional push to CRM / Sheet
Agent owns

What it says, the voice, knowledge, booking tools, call results, WhatsApp and email after the call.

Campaign owns

The list of people, when to dial, retries, and pushing hot leads out to a webhook or Sheet.

Connections own

The wires to the outside world: number, WhatsApp, email, Sheets, website form, Meta ads, calendar, meeting bots.

Sentence to repeat: Connections hold the keys. The agent only turns things on. If WhatsApp is not connected, after-call rules save but nothing is sent.

How SnapServe works

Users ask this first. Keep the five parts of a call.

What is SnapServe?

Software that talks on a phone or in a meeting, then can book, label the result, and follow up on WhatsApp or email.Open: Agents → New agent. Prove it with Live test.

How does a call work?

Number in → listen (speech to text) → think (the script + AI) → speak (voice) → do (book, transfer, end call). After hang-up: result + optional WhatsApp.Open: Agents → Overview for listen/think/speak. Actions for mid-call. After the call for follow-up.

Do I need my own AI key?

No. SnapServe runs the voice stack. Add your own keys only if you want to use your own OpenAI, Sarvam, and so on.Open: Settings → Providers. Skip this for Voiceathon unless they insist.

How is it billed?

Prepaid wallet. Calls and numbers come from that balance. Auto-pay can refill so a campaign does not stop.Open: Billing, or the wallet chip at the top.

First 15 minutes

If they say “where do I start?”

How do I make an agent?

Agents → New agent. Prefer Vibe Build if they want speed, Manual Build if they want every field. Write a greeting line. Live test 60 seconds. Fix the script. Then optionally assign a phone number.

How do I hear it without a number?

Open the agent → Live test → Start call. Browser microphone. No telephony charge for that test.

How do I call a real phone?

Buy or assign a number, then on the agent click Call and type the number. Wallet must have balance. India numbers need Verification (KYC) first.Open: Phone numbers → Get number. Then Agents → Call.

Agent and call questions

How do I change what it says?

Agent → Script. Greeting is the first line on the call. The display name is only an internal label — put the company name in the greeting and the script.

How do I change the voice / language?

Agent → Sound. Language and voice live there. Overview also shows transcriber, model, and voice in one place.

Can it book a meeting?

Yes, if a calendar is connected and the agent has the check-availability and book tools on. It can only offer times that exist on the calendar grid (for a 30 minute meeting, 9:00, 9:30, 10:00 — not 10:45 unless you change duration or hours).Open: Connections → Bookings calendar. Agent → Actions. Bookings to see hours.

Can it transfer to a human?

Yes. Mid-call transfer is an Action on the agent. Live handoff between two AI agents is Squads, not a campaign setting.Open: Agent → Actions. Or Squads. History → Transfers to see what happened.

What is a disposition / outcome?

The label when the call ends: Interested, Not interested, Callback. The AI picks it. You map those labels to funnel meaning for analytics.Open: Agent → After the call. Proof: History on that call.

How does memory work?

The agent can remember facts about a repeat caller. You can reset one caller if a fact is wrong.Open: Memory in the More menu.

How does knowledge work?

Upload a PDF, paste text, or add Q&A. Attach the pack to the agent so it looks up instead of guessing.Open: Knowledge → Add knowledge → Attach to the agent.

Where is the recording?

History → click the call. Transcript and recording are on that page.

How do I put it on my website?

Agent → Settings → Generate embed code. Paste on the site. Visitors talk in the browser. That is a webcall, not a phone DID.

Campaigns and lists

How do I call 500 people?

Campaigns → CSV file (or Sheets). Pick the agent, map the phone column, set hours, Create campaign. Pause / Resume / Stop from the list.Proof: Campaign → Live Queue, then History.

What is a batch?

Another set of contacts added to the same campaign. Create Batch on the campaign page.

What is Re-campaign?

Call the same people again, for example everyone who did not pick up. It does not create a new agent.

Why did it not dial?

Check: campaign is not Paused/Stopped, calling hours, wallet balance, number assigned, KYC done, phone column mapped. Then look at Live Queue.

Integrations — what they ask, what you say

All of these start at Connections unless noted. Do not send them hunting in Campaign Configuration for WhatsApp.

WhatsApp

How do I send WhatsApp after a call?

Two places. First connect WhatsApp. Then on the agent, After the call, turn on WhatsApp for every call or for selected outcomes. Test with a real call, then check the phone.Open: Connections → WhatsApp → Instant. Then Agents → After the call → Save Outcomes.

Do I need Meta Business / WABA?

Not for Voiceathon. Use Instant WhatsApp. Meta and BYON are extra. If an old custom webhook is still connected, Instant may not send — disconnect the old one.

Can it WhatsApp during the call?

Possible as a mid-call Action, but for demos keep WhatsApp after the call. Mid-call messages often confuse the conversation.

Google Sheets

How does Sheets calling work?

Connect Google. Start automatic calls: sheet URL, phone column, agent. A new row in the calling window starts a dial. Outcomes can write back to the sheet.Open: Connections → Google Sheets → Start automatic calls. Proof: add a test row, watch Live Queue.

Website form

How do I call when someone fills my form?

Create a website campaign, paste the embed or webhook into the form. Submit a test lead. The campaign queue should pick it up.Open: Connections → Form intake, or Campaigns → Website.

Meta Lead Ads

Can Facebook / Instagram leads get a call?

Yes. Connections → Meta Lead Ads, or Campaigns → Meta. Needs a Meta ad account. Skip for most Voiceathon teams unless they already run ads.

Email

How do confirmation emails go out?

Connect Email (Brevo) under Connections. Then After the call on the agent, turn on email for the outcome you want. Booking confirmation can also follow a successful book_appointment — do not invent a send_email tool in the script.

Calendar / bookings

How does calendar integration work?

Connect the bookings calendar, set event type (length) and availability hours. Enable check availability and book on the agent. The agent offers real free slots only.Open: Connections → Bookings calendar, then Bookings → Event Types and Availability.

Is that the same as meeting bots?

No. Bookings calendar = book a slot on a phone call. Meeting bots = the agent joins Meet, Zoom or Teams. Different cards on Connections.

Meeting bots

How do I put the agent in a Google Meet?

Enable Meetings on the agent. Open meeting bots, pick the agent, paste the link, Join. Admit the bot if the room asks.Open: Connections → Open meeting bots, or /app/meet.

Zoho / CRM

Do you have Salesforce / HubSpot?

Native campaign source includes Zoho. For other CRMs: Event subscriptions or campaign Lead transfer to their webhook URL, or Agent Settings → Post-call notify. Do not promise Salesforce as a one-click card.

API / developers

Can I trigger a call from my app?

Yes. Create an API key. Docs are at app.snapserve.ai/docs. Also MCP for coding agents.Open: Developers → New Key. Documentation in the sidebar.

Four kinds of “webhook”

People say webhook for four different jobs. Ask which direction first: SnapServe calling them, or them sending leads to us.

Event subscriptions

Workspace-wide: when a call finishes, we POST to their URL.Open: Developers → Event subscriptions → Add endpoint.

Post-call notify

Same idea, but only for one agent.Open: Agent → Settings → Post-call notify.

Form intake / website webhook

Their website sends a lead in. We dial.Open: Connections → Form intake, or Campaigns → Website.

Lead transfer

After the call, hot dispositions get pushed to their CRM URL or a Sheet. This is not WhatsApp.Open: Campaign → Configuration.

Mid-call HTTP tool

During the conversation the AI can call their API (check order, create ticket).Open: Agent → Actions / tools.

Voiceathon questions

Participants want a working demo, not every feature.

What should we build?

A real India problem + live call or meeting + at least three platform pieces + one data loop (website or Sheets or WhatsApp) + a 3-minute story.

What is the fastest winning path?

Hour 1: agent + Live test. Hour 2: outcomes. Hour 3: Website or Sheets. Hour 4: Instant WhatsApp after the call. Optional: squad or meeting bot. Skip Meta WABA, BYON, Zapier unless a mentor asks.

Do we need a phone number?

Webcall is enough to iterate. For judging, one real phone call or a meeting join is stronger. Keep wallet topped up.

How do judges score?

Named problem, live demo, depth (three capabilities), conversation stays on script, integration visible (trigger → call → outcome), tight story. Have a 30-second recording if the network dies.

Example demos

Healthcare: booking + WhatsApp + disposition. School: Hindi + Sheets + memory. Hiring: squad qualifier then scheduler. Local business: website form → call + Instant WhatsApp. Meetings track: bot joins Meet with a deck.

Do not mix these up

Callback vs transfer vs squad

Callback = call them later. Transfer = live pass to a human on this call. Squad = live pass from agent 1 to agent 2 on the same line.

After-call WhatsApp vs lead transfer

WhatsApp is on the agent. Lead transfer is on the campaign and pushes data, it does not send WhatsApp.

Bookings calendar vs Meet calendar

Bookings = slots the phone agent can offer. Meet page Google connect = auto-join a video event. Different screens.

Live test vs Call

Live test = browser. Call = real phone number. Campaign = many numbers from a list.

People / Call plans / Automation

Old names. They redirect to Campaigns or Home. Use the live menu: Home, Campaigns, Agents, Phone numbers, Connections, History, Analytics.
