Website setup

  1. Create a Campaign with Website/Webhook lead source and assign an Agent.
  2. Open Connections; copy /api/webhooks/lead/{token}.
  3. Map the real payload key to phone; optionally map name and email.
  4. For production, set an HMAC secret and sign the exact raw request body.
  5. Use Listen mode for a sample, then POST a controlled test lead.
  6. Check campaign_leads, queued/calling status, provider callback, call History, and outcome.
Duplicate risk: generic website submissions have no phone-level dedupe. Make the source form idempotent and disable repeated submits.
Queue reasons: campaign paused/stopped, outside business hours, DNC/TRAI, concurrency, attempts, wallet, or provider failure.

Setup

  1. Meta path: enter Business, WABA ID, Phone Number ID, permanent token; connect to an Agent.
  2. Fetch/pick an approved template; set Agent → After the call rule or add send_whatsapp.
  3. Test with a call containing caller speech and a completed/booking outcome.

Difficult questions and demo warnings

Do not demo / promise
  • Vonage, Exotel/Tata, Salesforce, Stripe, AWS Polly adapter, OpenAI Realtime.
  • New Instant/shared WhatsApp enrollment.
  • Cal.com or full warm-transfer briefing on Gemini Live.
Explain with caveat
  • Team workspace sharing: agents/calls are workspace-aware; campaigns/KB/squads are not uniformly shared.
  • Direct Meta WhatsApp: outbound works; native inbound/status/chatbot is not implemented for this path.
  • Knowledge: semantic vector search can fall back to full-text only.
  • Webhook delivery: retries exist, but these paths are not a durable outbound queue.
  • Connections Listen: in-memory and replica/restart sensitive.

Debugging and essential files

Five-step debugging pattern

  1. Name the exact path: provider, route, Agent ID, call/lead ID, and direction.
  2. UI/request: inspect payload, auth type, response, and client/workspace context.
  3. Database: confirm row/column changed—not just a success toast.
  4. Runtime: confirm createSession loaded the same Agent and provider keys.
  5. External callback: inspect provider response, status webhook, retries, timeout, and final History.
Agent silentCarrier/WS → key → STT final → LLM timeout/tool → TTS → wallet/logs.
Tool failsSaved live tool → valid name/schema → provider support → HTTPS/SSRF → timeout.
