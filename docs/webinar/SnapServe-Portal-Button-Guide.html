SnapServe

What does this button do?

A plain-English guide to every screen and every button in the SnapServe portal. Made for the webinar, so anyone on the team can answer a participant instantly. Type in the search box to jump straight to a button.

Getting around

The menu on the left is the same on every screen. This is what each item opens.

Main menu

Home

Your starting screen. Shows what needs attention today and quick links to create things.

Campaigns

Calling lists. This is where you upload contacts and let the agent call them.

Agents

Your AI callers. Create one, write what it should say, and test it.

Phone numbers

Buy a number, and choose which agent answers it.

Connections

Connect outside tools: WhatsApp, email, Google Sheets, your website form, Meta lead ads, calendar, meeting bots.

History

Every call that happened. Recording, transcript and result of each one.

Analytics

Numbers and charts: how many calls, how many connected, how many booked.

More menu

Knowledge

Company information you give the agent, so it can answer questions correctly.

Memory

What the agent remembers about each caller from earlier calls.

Squads

A group of agents that pass a call to each other, like a small team.

Bookings

Your calendar. Meetings the agent booked, and the times you are free.

Settings menu

Workspace

Company details, team members, appearance, and account settings.

Providers

Bring your own AI keys and pick the voices you want.

Developers

API keys and webhooks, for connecting SnapServe to your own software.

Billing

Your wallet balance, add money, and see where the money went.

Top of the screen

Search…

Find any agent, call or campaign by typing. Keyboard shortcut is Ctrl+K, or Cmd+K on Mac.

New agent

Creates a new AI caller. Available from anywhere in the portal.

Wallet chip

The balance shown near the top. Click it to add money.

Documentation

The full written help guide.

Settings

In the user menu. Opens your workspace settings.

Light appearance

Switches the portal to the light colour theme.

Dark appearance

Switches the portal to the dark colour theme.

Sign out

Logs you out of the portal.

On a phone

Bottom bar

Five shortcuts at the bottom of the screen: Home, Campaigns, Create, Agents, History.

Create

The centre button on the phone bar. Opens the new agent box.

When you click New agent

Vibe Build

You describe your business in normal words and the AI builds the agent for you in a few minutes.

Manual Build

You set up every detail yourself: script, voice, actions.

Open builder

Goes straight to the builder. Shown instead of the two options above when your account is managed by a partner.

Some accounts are managed by a partner. Those users see fewer menu items, for example no Providers. That is normal, not a fault.

Home

The first screen after you log in.

Open agent

Opens your agent so you can edit or test it.

New campaign

Starts a new calling list.

Setup checklist

Short list of the first three things to do: create an agent, create a campaign, connect a phone or channel. Each line is clickable.

Agents

An agent is your AI caller. This screen has the list on the left and the builder on the right.

Making a new agent

New agent

Starts creating an agent.

Build with AI

Describe the business, and the AI writes the script and settings for you.

Configure manually

You fill in everything yourself.

Create agent

Saves the new agent and opens it.

Buttons at the top of the builder

Call

Makes the agent ring a real phone number so you can hear it on a live call.

Live test

Talk to the agent right now through your computer microphone. No phone number needed.

Close test

Closes that test panel.

Save

Saves your changes. It shows Saving while it works and Saved when it is done.

Phone test

Same as Call. This is the name it uses on a phone screen.

Publish version

Takes a snapshot of the agent as it is now, so you can come back to it later.

Refine with AI

Reopens the AI builder to improve an agent you already made.

API keys

Shortcut to the Providers screen, where the AI keys live.

Delete agent

Removes the agent permanently.

The test call box

Call

Starts the test call to the number you typed. Shows Calling while it connects.

Cancel

Closes the box without calling.

Start call

In the browser test panel. Begins talking to the agent.

End call

Hangs up the browser test call.

The tabs inside the builder

Overview

A summary of the agent and its main settings in one place.

Script

What the agent says and how it behaves. The most important tab.

Sound

Voice, language and speaking style.

Actions

Things the agent can actually do on a call: book a meeting, transfer to a person, send WhatsApp, end the call.

After the call

What happens once the call ends. Set the result of the call and send follow-up messages.

Activity

Recent calls made by this agent.

Settings

Advanced options, including the website widget.

Versions

Older saved copies of the agent.

Inside Script

Generate

The AI writes the script for you from a short description.

Inside After the call

Add rule

Adds a rule such as: if the call result was Interested, send this WhatsApp message.

Save Outcomes

Saves your call results and follow-up rules.

Inside Settings, website widget

Generate embed code

Creates a small piece of code. Paste it into your website and visitors can talk to the agent from there.

Copy

Copies that code to your clipboard.

Regenerate token

Creates a new secret link and stops the old one working. Use this if the old link leaked.

Inside Versions

Publish Version

Saves the current setup as a named version you can return to.

Campaigns

A campaign is a list of people to call, plus the agent that calls them.

Where the contacts come from

CSV file

Upload a contact list from Excel or a spreadsheet file.

Sheets

Connect a Google Sheet. New rows are called automatically as you add them.

Website

Calls people the moment they fill a form on your website.

Meta

Calls leads that come from Facebook and Instagram ads.

Zoho CRM

Pulls contacts from your Zoho CRM.

On the campaign list

Export

Downloads the list as a spreadsheet file.

Clear

Removes the filters you applied, so you see everything again.

Pause

Stops calling for now. You can start again later.

Resume

Starts calling again after a pause.

Stop

Ends the campaign. Remaining contacts are not called.

Edit

Change the campaign name, agent or settings.

Delete

Removes the campaign completely.

Start a CSV campaign

Shown when you have no campaigns yet. Begins the upload steps.

Opens a short help panel explaining how campaigns work.

Finishes and creates the campaign. On some steps it says Create list.

Overview

Analytics

Live Queue

Calls happening right now, live.

Incoming

People from this list who called you back.

Callbacks

Calls the agent promised to make again later.

Transfers

Calls that were passed to a human.

Bookings

Meetings booked from this campaign.

Configuration

The settings of this campaign.

View Analytics

Opens the full analytics screen for this campaign.

Create Batch

Adds another set of contacts to the same campaign.

Activate

Turns a stopped continuous campaign back on.

Re-campaign

Calls the same people again, for example everyone who did not pick up.

Phone numbers

The number your agent calls from, and the number customers call in on. Two tabs: My numbers and Verification.

Get number

Opens the buying steps for a new phone number.

Get Your First Number

The same thing, shown when you have no numbers yet.

Search

Shows the numbers available to buy.

Apply

Applies a coupon code to the price.

Purchase Number

Pays for the number and adds it to your account.

Get number free

Assign

Reassign

Moves the number to a different agent.

Rules

Decides who answers based on time or the caller, for example office hours to one agent and nights to another.

Save

Release

Gives the number back. You stop paying for it and you cannot get that same number again.

Verify Identity

Resume Verification

Back

Goes one step back in the buying steps.

Cancel

Leaves the buying steps.

Bookings

The calendar behind the agent. It decides which times the agent is allowed to offer on a call.

The tabs

Bookings

Meetings that are already booked.

Setup

The quick way to get your calendar working.

Calendars

Your calendars and their time zone.

Event Types

The kinds of meeting you offer, such as a 30 minute demo.

Availability

The days and hours you are free.

Conferencing

Connects Google Meet so every booking gets a meeting link.

The buttons

New Calendar

Creates a calendar.

Create a calendar

The same thing, shown when you have none.

Add schedule

Adds a set of working hours, for example Monday to Friday, 9 to 6.

Confirm booking

Approves a meeting that is waiting for approval.

Reschedule

Moves a booked meeting to another time.

Cancel booking

Cancels the meeting and tells the customer.

Keep

Changes your mind and keeps the meeting.

Back to Event Types

Returns to the list of meeting types.

Common question: why did the agent not offer 10:45? The agent can only offer times that fit your meeting length. With a 30 minute meeting starting from 9:00, the available times are 9:00, 9:30, 10:00 and so on. Change the meeting length or the start of your working hours in Event Types and Availability.

Workspace

Your company account. Two tabs: Workspace and Team.

Invite Member

Sends an email invite so a colleague can log in.

Update password

Changes your login password.

Add concurrent slot

Buys the ability to run one more call at the same time. Two slots means two calls at once.

Light / Dark / System

The colour theme. System follows your computer setting.

10 s / 30 s / None

How long the agent waits in silence before ending the call.

Delete from SnapServe

Deletes the whole workspace. You have to type DELETE to confirm. It cannot be undone.

Profile

Your own name and details.

Audit Logs

A record of who changed what.

Providers

The AI services behind the agent. Three tabs: Provider keys, Voices, My clones.

Add Provider

Use your own account with an AI company instead of ours. Billing for that part then goes to you.

Voices

Listen to the available voices and choose one.

My clones

Voices made from your own recording.

Developers

For connecting SnapServe to your own software. Two tabs: API keys and Event subscriptions.

New Key

Creates a key your software uses to talk to SnapServe.

Create Key

Confirms and generates it.

I've saved my key

Closes the box showing the key. The key is shown only once, so copy it first.

Revoke Key

Switches a key off immediately. Anything using it stops working.

Add endpoint

Give a web address and SnapServe will notify it every time a call finishes.

Delete

Removes that address.

Billing

Money in and money out. Two tabs: Wallet and Usage.

Pay

Adds money to your wallet. The button shows the amount, for example Pay ₹1,000.

Preset amounts

Quick buttons for common top-up amounts.

Set Up Card Auto-pay

Saves your card and tops up automatically when the balance runs low, so calls never stop mid-campaign.

Usage

Shows where the money went: calls, minutes and numbers.

Links you share with customers

These pages are seen by your customers, not by your team. No login needed.

Call link

A web page where anyone can talk to your agent from a browser. No phone call, no charges for them.

Continue

The visitor agrees to use the microphone.

Start call

The visitor begins talking to the agent.

End call

The visitor hangs up.

Booking page

A page where a customer picks a time themselves. They can also cancel or move it later.

Website widget

The code from Generate embed code. It puts a call button on your own website.

Words people ask about

If a participant asks what a word means, this is the short answer.

Agent

The AI that talks on the phone. You decide what it says.

Campaign

A list of people to call, plus the agent that calls them.

Batch

One group of contacts inside a campaign.

Lead

One person in that list.

Outcome

The result of a call, for example Interested or Not interested. Also called a disposition.

Transfer

The agent passes the live call to a human.

Callback

A call the agent promised to make later.

Webcall

A call through a web browser instead of a phone line.

Knowledge pack

A file or set of answers the agent reads from.

Squad

Several agents that hand a call to each other.

Concurrent slot

One call happening at the same time. Ten slots means ten calls at once.

Wallet

Verification

The identity check the telecom rules require before you can use a number.

Provider key

Your own account with an AI company, used instead of ours.

API key

A password your software uses to control SnapServe.

Event subscription

Version

A saved copy of an agent from a point in time.

Building an agent by describing your business in normal words.
